# Namya AI: Week 1 Setup Guide

**Goal:** By the end of Week 1, the Mac mini runs WAHA (the WhatsApp link) and
n8n (the automation tool), the Namya number is linked, a team test group
exists, and the "Namya Memory" Google Sheet is ready.

**Who does it:** Sanket, at the Mac mini, with Claude guiding in chat.
Sunil handles the phone and prices in Biratnagar.

**Time:** about 4-5 hours, split into 5 short sessions.

**Cost this week:** USD 0 (plus the SIM). No AI credit is needed until Week 2.

**Design:** `namya-ai/docs/specs/2026-10-21-phase1-design.md`

## Rules for the whole week

- Do one step, check the "You should see" line, then move on.
- If anything looks different, stop and send Claude a screenshot.
- Never share the `.env` file or its passwords in WhatsApp or email.
- Everything only works on the Mac mini itself (`localhost`). That is on
  purpose: nobody on the internet can reach it.

## Things that can go wrong (and what to do)

1. **Mac goes to sleep or loses power:** Namya stops. After a power cut,
   log in to the Mac; Docker and Namya restart by themselves.
2. **Namya phone is off for many days:** WhatsApp unlinks the Mac after
   about 14 days offline. Keep the phone charged and on Wi-Fi.
3. **WhatsApp logs the Mac out:** the WAHA dashboard shows a new QR code.
   Scan it again from the Namya phone (Session 3, step 5).
4. **"Port already in use" error:** another app uses port 3000 or 5678.
   Send Claude the message.
5. **macOS update restarts the Mac:** log in again; check both dashboards.

## Session 1: Mac settings and Docker (about 1 hour)

- [ ] **1. Stop the Mac from sleeping.** Apple menu  > **System Settings** >
      **Energy**. Turn on:
      - "Prevent automatic sleeping when the display is off"
      - "Wake for network access"
      - "Start up automatically after a power failure"

      You should see: all three switches blue.
- [ ] **2. Download Docker Desktop.** Go to `https://www.docker.com/products/docker-desktop/`.
      Click **Download for Mac**, and choose **Apple Silicon** if your chip
      says "Apple M...", otherwise **Intel**.
      (Docker Desktop is free for businesses under 250 staff.)
- [ ] **3. Install it.** Open the downloaded `Docker.dmg`, drag the whale icon
      into **Applications**. Open Docker from Applications. Accept the terms.
      Choose **Use recommended settings**. Skip sign-in if asked.

      You should see: a whale icon in the top menu bar.
- [ ] **4. Make Docker start by itself.** Click the whale > **Settings** (gear)
      > **General**. Tick "Start Docker Desktop when you sign in to your
      computer". Click **Apply**.
- [ ] **5. Give Docker enough memory.** Settings > **Resources**. Set Memory
      to **4 GB**. Click **Apply & restart**.
- [ ] **6. Check Docker works.** Open **Terminal** (press Cmd + Space, type
      "Terminal", press Enter). Paste this and press Enter:

      ```
      docker run --rm hello-world
      ```
      You should see: "Hello from Docker!" in the text.

## Session 2: Install Namya's tools (about 1 hour)

- [ ] **1. Download and run the setup script.** In Terminal, paste:

      ```
      curl -fsSL https://raw.githubusercontent.com/koshish369/Blink-protfolio/claude/namya-ai-kickoff-rwy8b2/namya-ai/setup/install.sh | bash
      ```
      You should see: "Setup files are ready in /Users/<you>/namya".
- [ ] **2. Start the tools.** Paste:

      ```
      cd ~/namya && docker compose up -d
      ```
      The first time this downloads about 1-2 GB, so it can take 5-15 minutes.

      You should see: two lines ending in "Started" (waha and n8n).
- [ ] **3. Check both are running.** Paste:

      ```
      docker compose ps
      ```
      You should see: `waha` and `n8n`, both with STATUS "Up".
- [ ] **4. Find your passwords.** Paste:

      ```
      open -e ~/namya/.env
      ```
      A TextEdit window opens. Save `WAHA_DASHBOARD_USERNAME`,
      `WAHA_DASHBOARD_PASSWORD` and `WAHA_API_KEY` in your password manager
      (or Apple Passwords). Close TextEdit without changing anything.
- [ ] **5. Open the WAHA dashboard.** In Safari or Chrome go to
      `http://localhost:3000/dashboard` and log in with the username and
      password from step 4.

      You should see: the WAHA dashboard with a "default" session (or an
      option to add one).
- [ ] **6. Open n8n.** Go to `http://localhost:5678`. Create the owner
      account (your email and a new strong password; save it too).
      Skip the survey.

      You should see: an empty n8n "Overview" page.
- [ ] **7. Send Claude** a screenshot of `docker compose ps` and both pages.

Needs the Namya phone. If Sunil has it in Biratnagar, do this on a video

- [ ] **7.** Back in the WAHA dashboard, keep the status page open for a
      minute. You should see: still **WORKING**.

## Session 4: The "Namya Memory" Google Sheet (about 45 minutes)

- [ ] **1.** Go to `https://sheets.new` while logged in to the Blink Google
      account. Rename the file (top left) to **Namya Memory**.
- [ ] **2.** Create 5 tabs (the **+** at the bottom left). Rename them
      (double-click the tab name) exactly:
      `Groups`, `Messages`, `Group Notes`, `To do`, `Prices`.
- [ ] **3.** Type these headers in row 1 of each tab, one per column,
      starting at column A:

      | Tab | Row 1 headers |
      |---|---|
      | Groups | Group ID, Client name, Project, Region, Status |
      | Messages | Time, Group ID, Group name, Sender, Text, Has file |
      | Group Notes | Group ID, Summary, Last updated |
      | To do | Group ID, Item type, Details, Due date, Status, Created |
      | Prices | Package, What's included, Price (NPR), Notes |

- [ ] **4.** Freeze row 1 on each tab: **View** > **Freeze** > **1 row**.
- [ ] **5.** Share with Sunil as **Editor** (Share button, top right).
- [ ] **6.** Sunil fills the **Prices** tab with the standard packages.
      Only prices written here can ever be quoted by Namya.
- [ ] **7.** In **Groups**, add one row: Group ID `test` (Claude fills the
      real ID in Week 2), Client name `Namya Test`, Project `Testing`,
      Region `Nepal`, Status `active`.
